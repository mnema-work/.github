# Contributing

Thank you for wanting to help. Each repository of the mnema-work organization says how to work in it in its own
`CONTRIBUTING.md`, and that page takes precedence over this one; the product's is in
[mnema](https://github.com/felipesauer/mnema/blob/main/CONTRIBUTING.md).

Where a repository has no page of its own:

- Open an issue or a discussion before a large change, so that its direction is agreed before the work.
- One change per pull request, described in English: what it changes and why, and how it was checked.
- Pull requests from a fork run their checks once a maintainer approves them.
- By contributing you agree that your contribution is licensed under the repository's license, and you follow the
  [code of conduct](CODE_OF_CONDUCT.md).
