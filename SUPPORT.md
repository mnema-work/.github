# Getting help

- **How do I…?** Start with the docs at [mnema.work/docs](https://mnema.work/docs/).
- **A question or an idea:** open a thread in [Discussions](https://github.com/felipesauer/mnema/discussions).
  Discussions are public.
- **Something does not work:** open an [issue](https://github.com/felipesauer/mnema/issues/new/choose) and pick the
  form that fits. If mnema stopped with an internal error, run `mnema report`: it shows what it would say about the error, sends nothing, and gives the link to the form for it.
- **A security problem:** never in public; see the [security policy](SECURITY.md).
- **Anything else:** hello@mnema.work.
