### mnema is the decision record for AI coding agents.

Who decided this, and why? What was turned down? Has it changed since? When an agent settles a choice in a chat
that ends, nothing answers. mnema keeps the answer in the repository: a signed, append-only record of the
decisions behind the work, handed to each agent session, held at the edits it governs, and checkable by anyone,
offline.

[Website](https://mnema.work) · [Docs](https://mnema.work/docs/) · [Repository](https://github.com/felipesauer/mnema) · [npm](https://www.npmjs.com/package/@mnema/code)

</div>

```sh
npm install -g @mnema/code
mnema init
```
